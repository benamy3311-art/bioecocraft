# BIOECOCRAFT

Juego educativo de agroecología y bioeconomía regenerativa con Hempy.

**Versión jugable: 0.8.4.**

## Jugar

https://benamy3311-art.github.io/bioecocraft/

En teléfonos, jugar en horizontal. La partida se guarda en el navegador y no se sincroniza entre dispositivos ni con archivos locales.

Este repositorio contiene únicamente la distribución web del juego. La publicación usa GitHub Pages desde la carpeta `docs`.

Todos los derechos reservados sobre el juego y su arte.
